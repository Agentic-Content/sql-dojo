# SQL Dojo — Publications

Interaktives SQL-Lerntool für unser Team, gebaut auf Basis der Publications-Übungsdatenbank aus dem MySQL-Kurs.

## Benutzung

1. [`SQL_Dojo_Publications.html`](./SQL_Dojo_Publications.html) herunterladen (oder direkt im Browser öffnen)
2. Datei im Browser öffnen (Doppelklick reicht) — beim Öffnen wird kurz Internet gebraucht, danach läuft alles lokal
3. Thema wählen und loslegen, oder direkt in den Freeplay-Modus

## Was drin ist

- Alle Themen aus dem Kurs: SELECT/FROM, WHERE, ORDER BY, LIKE/IN, GROUP BY, JOINS, CASE WHEN, Subqueries, Funktionen, Advanced Mix
- Echte Auswertung gegen die echte Datenbank (keine Musterlösungs-Rateri, sondern tatsächliche Abfrage-Ergebnisse)
- Freeplay-Modus: Thema bleibt verdeckt, du musst es selbst erkennen
- Gestuftes Tipp-System bei Bedarf
- Schema-Browser mit Spickzettel links im Tool

Reines Übungs- und LernTool, keine Ergebnisse werden geteilt oder gespeichert.
